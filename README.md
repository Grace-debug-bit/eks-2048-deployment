# eks-2048-deployment
Deploying the 2048 game on AWS EKS Fargate using AWS Load Balancer Controller, Ingress and ALB


EKS Fargate Deployment with ALB Ingress — Deployed a containerized application on Amazon EKS using AWS Fargate profiles, eliminating node provisioning and patching. Installed the AWS Load Balancer Controller with Helm and configured IAM Roles for Service Accounts (OIDC) to provision an Application Load Balancer through Kubernetes Ingress, routing internet traffic to pods via target groups. Provisioned with eksctl; code on GitHub
